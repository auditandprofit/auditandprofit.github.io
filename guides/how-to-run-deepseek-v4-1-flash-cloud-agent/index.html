How to run a DeepSeek V4.1 Flash cloud agent

A good first run is small enough to verify, but specific enough that the agent knows what success looks like.

1. Name the job and state the outcome

Open Cloud Agents and give the job a short name you will recognize later. In the task field, start with the result you want. Then give the relevant starting point: a repository, a file, a question to investigate, or the output you need.

Keep the first outcome contained. “Find why this test fails and explain the smallest fix” is easier to review than “improve the project.”

2. Add the constraints and checks

Name anything the agent must not change, the tools or files it should use, and the checks that must pass. Say what the final result should include. These details let the agent make choices without guessing what you meant.

Goal: Fix the failing parser test.
Starting point: Read the failing test and parser module.
Constraints: Keep the public command unchanged.
Checks: Run the parser test suite.
Definition of done: Explain the cause and list changed files.

3. Choose a run length and start

Choose only as much time as the task needs. Individual runs currently last up to three hours. Start the job, then open its dedicated page. The job output appears there while the run is working.

4. Review the output and workspace

Read the output for what the agent tried, what it checked, and its result. When a finished workspace archive is available, download it to inspect the files from the run. This gives you something concrete to keep or compare before changing a larger project.

5. Rerun with the next useful instruction

A rerun is for refinement, not a blind repeat. If the first pass found a missing requirement, say exactly what to do next. For example: “Keep the parser change, add the two boundary tests, and rerun the suite.”

Current access boundaries

Free accounts run one active cloud agent at a time. The current paid plan is listed as $10 USD for 30 days with up to 10 active agents. Individual runs last up to three hours and can be rerun.

Cloud Agents is building toward free unlimited DeepSeek V4.1 Flash tokens and cloud-agent runtime. That goal does not remove the current per-run boundary.

Questions

How do I run a DeepSeek V4.1 Flash cloud agent?

Open Cloud Agents, give the job a useful name, write a focused task, select a run length up to three hours, and start the run. Its own page shows its output as it arrives.

What should I put in a cloud-agent task?

State the goal, starting context, constraints, checks to run, and what counts as done. A focused task gives the agent a concrete outcome to work toward.

What happens after a cloud-agent run?

Review the job output, download the finished workspace archive when it is available, and rerun with a clearer next instruction if more work is needed.
