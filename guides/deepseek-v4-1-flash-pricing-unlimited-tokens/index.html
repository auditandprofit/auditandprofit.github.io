DeepSeek V4.1 Flash pricing, tokens, and cloud agents

Cloud Agents is a prompt-to-cloud-agent service built around DeepSeek V4.1 Flash. This page separates the current access limits from the long-term unlimited-access goal.

Current access at a glance

Model
DeepSeek V4.1 Flash

Free unlimited tokens and cloud-agent runtime

A custom account limit can be set by the service administrator.

What “unlimited tokens” means

The service goal is free unlimited DeepSeek V4.1 Flash tokens and unlimited cloud-agent runtime. That is the direction of Cloud Agents, not a claim that the current individual-run limit does not exist.

Today, one run can last up to three hours. When more time is needed, rerun the task with the same prompt or a clearer next instruction.

What the paid plan is for

The current paid option is a flat $10 USD for 30 days, not a per-agent charge. It is for people who need several jobs working in parallel. For example, one agent can inspect a bug while another writes tests and another researches an approach. Each job still has its own logs and finished-workspace archive when available.

What to check before starting

  • Use the current plan details shown in the app before paying.
  • Use the three-hour run limit when planning a task.
  • Describe the output and checks you need in the prompt.
  • Read the logs and download the archive when the run is complete.
