Cloud-agent logs, artifacts, and reruns

A useful cloud-agent run should leave a clear record: what it did, what it produced, and what to change if you run it again.

Read the job page as the run happens

Each Cloud Agents task has its own job page. Its log output is the live record of work arriving from the run. Read it for concrete signals: what the agent is trying, what completed, what failed, and what it plans to verify next.

Use an archive to keep the workspace

When a finished workspace archive is available, download it before treating the run as final. The archive is the handoff for files created or changed during the task. Logs explain the path the agent took; the archive is where you inspect the resulting files.

Rerun with a better next instruction

Rerunning starts the task as a fresh run. It is useful when the first pass gets close, reaches the time limit, or reveals missing context. Do not repeat the same vague prompt. Add the exact issue from the job output, the desired next change, and the check that should pass.

A simple review loop

  1. Read the last meaningful log lines.
  2. Open or download the finished workspace archive when available.
  3. Compare the result to the definition of done.
  4. Rerun with one precise next instruction if work remains.

Keep the task focused

Individual runs currently last up to three hours. Focused tasks finish more predictably and make the logs easier to review. Split large work into clear stages when the output shows that the scope is too broad.
