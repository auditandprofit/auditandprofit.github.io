# Cloud Agents

[Cloud Agents](https://auditandprofit.com/) is a prompt-to-cloud-agent service built around DeepSeek V4.1 Flash. Give an agent a focused task, follow its job output, and inspect a finished workspace archive when one is available.

This repository contains the lightweight static landing site and guides for Cloud Agents. The application itself is at [agent.kick.sh](https://agent.kick.sh/).

## Current service facts

| Access | Current details |
| --- | --- |
| Free | One active cloud agent at a time. |
| Paid | Currently listed at $10 USD for 30 days, with up to 10 active agents. |
| Run length | Up to three hours per run; a finished task can be rerun. |
| Product goal | Free unlimited DeepSeek V4.1 Flash tokens and cloud-agent runtime. This is a goal, not a claim that current runs have no limit. |
